用产品思维指挥 AI，把「种草灵感制造机」从痛点发现做到独立上线。一个拒绝 AI 瞎编、专治“输入困难症”的小红书文案生成器案例。

情境 & 任务
为什么我要做这个工具？
作为独立开发者，我经常需要写小红书文案。但我发现市面上的 AI 工具都有两个致命痛点：一是“输入困难症”，面对空白文本框不知道怎么写 Prompt；二是“AI 幻觉”，一旦漏填信息，AI 就开始一本正经地瞎编。

我的任务是：用产品思维重构 AI 交互，做一个能真正帮人干活，而不是只会陪聊天的生产力工具。
~ ~ ~ ✿ ~ ~ ~
️ 行动
我是如何解决痛点的？
我实施了 Input Engineering（输入工程前置化）。把复杂的 Prompt 封装成结构化表单，用户只需像填问卷一样勾选，AI 就能“看碟下菜”。

同时，我在底层加入了防幻觉拦截机制。当检测到关键信息不足时，系统会拒绝瞎编，并高亮提示补充，从源头保证可靠性。

协作过程 · Cursor
我如何用 Cursor 把 MVP 推到可演示？
对我来说，Cursor 不是「自动写完产品」的黑盒，而是可指挥的工程搭档。方向、取舍和验收标准始终由我定；AI 负责加速实现、对照文档排查、补齐样板代码。面试时我更想讲清楚「为什么这么做」，而不是「聊了多少轮」——所以先放三次真实 Prompt 截图作证据，再展开完整判断路径。

下面三张是当时真实的 Cursor 对话截图，按时间顺序：先定界面骨架，再接通流式接口，最后把输出收成 JSON 与缺失提醒。它们要证明的是产品判断和工程指令是否写清楚，而不是「AI 替我写了代码」。

对应到产品决策上，完整路径是这样走的：

  1. 01
    定问题边界：可演示，而不是大而全
    电商运营写小红书文案很耗时，但我不想一上来做「全能 Agent」。我把目标压成一句话：做一个面试官 30 秒能点开、能生成、能看懂设计取舍的 AI MVP。范围锁死在「结构化输入 → 流式种草文案 → 缺失提醒 → 可复制 / 可回看」，其余功能一律延后。
  2. 02
    选栈：先交付，再炫技
    我选了 Next.js App Router + Tailwind + shadcn/ui：组件现成、部署路径清晰、和 Vercel AI SDK 契合。Cursor 帮我搭脚手架与 UI 骨架，但我主动砍掉了过度抽象——MVP 阶段优先「左右栏一屏完成任务」，而不是先堆设计系统。
  3. 03
    产品设计迭代：把 Prompt 藏进表单
    交互从「空白对话框」改成左输入 / 右输出：四字段结构化信息（商品名、卖点、人群、价格）+ 文案风格下拉。输出侧约定 JSON（标题、正文、missing_params），再做成 Markdown 预览、纯文本复制和 LocalStorage 历史。每一步都是在回答同一个问题：用户还要不要自己写 Prompt？
  4. 04
    接入模型：从「兼容层」收敛到 DeepSeek
    初期我按 OpenAI-compatible 思路接流式生成，便于换模型；落地时明确切到 DeepSeek + Vercel AI SDK（streamText），并在 README 写清：面试官要看真演示，必须配置真实 Key 再 Redeploy。关键决策是流式 + 结构化 JSON——边生成边预览，同时用 missing_params 把「信息不够」暴露给用户，而不是假装写完了。
  5. 05
    踩坑与排查：我主导，Cursor 协助定位
    真实卡点包括：401 / 402（Key 无效或余额不足）、环境变量未生效、AI SDK 7 不再接受 messages 里的旧 system 写法（改用 instructions）、以及空流时报「模型未返回有效内容」。排查方式是分层验证——先确认 env 与鉴权，再对照 SDK 文档改传参，最后保证空响应变成可读错误而不是静默失败。Cursor 加速了对照源码与补丁，但复现路径和验收标准是我定的。
  6. 06
    上线与开源：让别人能复现
    部署到 Vercel，用环境变量注入 Key（绝不写进页面或仓库），并把 Demo / 本地启动 / 环境变量说明写进 GitHub README。对我而言，「能跑」不够，还要「别人按文档也能跑」——这才是可演示的工程闭环。
我希望面试官能听到的判断力：先锁范围，再选最快跑通的技术路径；用结构化输入约束模型，用明确报错暴露系统边界；把 Cursor 当加速器，把产品决策权留在自己手里。

结果 & 验收
我的产品验收标准
作为个人 MVP 项目，我没有做大规模用户测试，但我为自己设定了三个核心验收标准。只要达到这三点，我就认为产品是成立的：
️
交互 ≤ 3步
结构化表单替代空白输入框，用户无需思考 Prompt 怎么写
️
拒绝瞎编
关键信息缺失时触发拦截提示，而非强行生成错误内容
成本可控
单次生成消耗约 1000 Token，成本不到 1 毛钱，商业闭环成立
硬核排查彩蛋：在部署时，我遇到了 AI SDK 底层废弃旧传参的隐蔽 Bug。通过源码级分析，我主动重构路由层，彻底修复了流式输出中断问题，确保了生产环境的稳定。
